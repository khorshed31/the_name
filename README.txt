DIGITAL LETTER WEBSITE — VINTAGE BANGLADESHI LETTER EDITION

Files:
- index.html: complete website (HTML, CSS and JavaScript in one file)
- friend.jpg: add the chosen person's photo here (not included)

Personalize:
1) Open index.html in a text editor.
2) At the bottom, find:
   const FRIEND_NAME = "এখানে নাম লিখুন";
   const FRIEND_PHOTO = "friend.jpg";
3) Replace the sample name.
4) Put the chosen photo in the same folder and name it friend.jpg,
   or change FRIEND_PHOTO to match the filename.
5) Save and double-click index.html to open it in a browser.

Experience:
- Opening screen asks whether the visitor is ready to see a name.
- Choosing No ends the flow respectfully.
- Choosing Yes opens an anonymous, address-free letter in a vintage
  Bangladeshi postal style, with ruled paper, a postal mark and stamp motif.
- The photo and name reveal gradually over 8 seconds.
- They remain visible for 5 seconds, then the entire reveal glitches away.

No framework or external library is required.
